Data Labeller

AI-assisted media annotation pipeline for images, videos, and audio datasets

What this is

A three-stage pipeline for annotating media datasets with category labels and free-text descriptions. Tasks flow through admin creation, labeller annotation, automated AI quality control (Gemini), and human QC review. Built with Python/FastAPI, Turso (libSQL), and vanilla HTML/Tailwind CSS.
